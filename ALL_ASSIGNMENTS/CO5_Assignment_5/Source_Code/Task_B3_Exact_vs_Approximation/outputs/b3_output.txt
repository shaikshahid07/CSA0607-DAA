B3.2 COUNTEREXAMPLE FOR GREEDY
    C1 covers [1, 2, 4, 5]
    C2 covers [1, 2, 3]
    C3 covers [4, 5, 6]
    Greedy trace:
        C1 would newly cover 4 zone(s)
        C2 would newly cover 3 zone(s)
        C3 would newly cover 3 zone(s)
      -> choose C1 (gain 4), uncovered now [3, 6]
        C1 would newly cover 0 zone(s)
        C2 would newly cover 1 zone(s)
        C3 would newly cover 1 zone(s)
      -> choose C2 (gain 1), uncovered now [6]
        C1 would newly cover 0 zone(s)
        C2 would newly cover 0 zone(s)
        C3 would newly cover 1 zone(s)
      -> choose C3 (gain 1), uncovered now []
    GreedyCoverSize = 3 {C1, C2, C3}
    OptimalCoverSize = 2 {C2, C3}
    GreedyCoverSize > OptimalCoverSize : True
