===============================================

This folder contains 13 standalone Python programs. Each file begins with
a comment showing the question number and question name.

HOW TO RUN IN VS CODE
---------------------
1. Extract the ZIP file.
2. Open the extracted Python_Programming_Questions folder in VS Code.
3. Make sure Python 3 is installed and the Python extension is enabled.
4. Open the program you want to run.
5. Select Run Python File, or open Terminal > New Terminal and type:
   python Q01_First_Palindromic_String.py
6. Enter the requested input in the terminal. Each program runs separately.

INPUT FORMAT
------------
For arrays, enter numbers separated by spaces. For the palindrome question,
enter words separated by spaces.

NOTES
-----
- No third-party Python packages are required.
- Question 9 sorts the array before binary search because binary search
  requires sorted data. Its reported position is 1-based in the sorted array.
- Question 6 uses Python's built-in sort() because that question does not
  prohibit built-in sorting.
- Question 10 implements heap sort without a built-in sorting function.
